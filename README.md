# Hogger Reimagined

An encounter design pitch reimagining Hogger, the classic Elwynn Forest starter-zone mob, as a fully realized 5-player instanced boss fight for World of Warcraft: Forever.

**Live page:** https://upt3mpo.github.io/hogger-reimagined/

Covers a short narrative setup, a three-phase mechanic breakdown built around the camp's existing tents and campfires, and explicit pacing and tuning intent.
